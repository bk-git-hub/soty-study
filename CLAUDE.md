# CLAUDE.md

## Goal
Recreate the target design website **as close to pixel- and motion-perfect as possible**.
Target: [TARGET SITE URL]

## Rules
- Rebuild from observation (recordings and screenshots in `reference/`). Don't copy code from the original site.
- Never commit anything from `reference/` or original assets. Use licensed or self-made assets only.
- Compare side by side with the original after every change. Don't call something "matching" without comparing.
- Match motion, not just layout: timing, easing, delays and scroll feel.
- Keep 60fps on a mid-range phone.
- Explain non-obvious code (shaders, easing math) in short comments.
- Small, focused commits.
